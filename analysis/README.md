# Analysis

- [Current assessment](./current-assessment.md): short, current interpretation and next actions.
- [Open questions](./open-questions.md): unresolved history and clinician-facing follow-up.
- [Evidence summary](./evidence-summary.md): detailed result summaries and longitudinal reasoning log.

Keep facts from source records distinct from interpretation. Update the current assessment when the working conclusion changes; retain older reasoning in the evidence summary or dated research notes.
